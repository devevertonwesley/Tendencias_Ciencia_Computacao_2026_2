# Sistema de Rastreamento de Equipamentos

# Prompt Inicial:

Atue como um analista de sistemas.

Uma instituição de ensino precisa desenvolver um Sistema de Rastreamento de Equipamentos.

A instituição possui equipamentos como computadores, notebooks, projetores, tablets e equipamentos de laboratório. Atualmente, existe dificuldade para controlar onde os equipamentos estão, quem está utilizando cada item e registrar empréstimos, devoluções e movimentações.

Analise esse problema e identifique os principais requisitos funcionais e não funcionais necessários para o desenvolvimento do sistema.

Apresente a resposta de forma organizada, separando os requisitos funcionais dos requisitos não funcionais.

---

# Resposta:

Requisitos funcionais:

O sistema deve permitir cadastrar equipamentos.

O sistema deve permitir editar e excluir equipamentos.

O sistema deve registrar a localização dos equipamentos.

O sistema deve registrar empréstimos e devoluções.

O sistema deve identificar o responsável por cada equipamento.

O sistema deve permitir consultar o histórico de movimentações.

O sistema deve informar a situação do equipamento, como disponível, emprestado ou em manutenção.

O sistema deve permitir pesquisar equipamentos.

---
Requisitos não funcionais:

O sistema deve possuir uma interface simples e fácil de utilizar.

O acesso ao sistema deve ser protegido por autenticação.

O sistema deve manter os dados dos equipamentos armazenados com segurança.

O sistema deve apresentar bom desempenho nas consultas.

O sistema deve ser acessível por diferentes dispositivos.

# Prompt Melhorado:

Atue como um analista de sistemas especializado em levantamento e documentação de requisitos.

Uma instituição de ensino precisa desenvolver um Sistema de Rastreamento de Equipamentos para controlar computadores, notebooks, projetores, tablets e equipamentos de laboratório.

O sistema deverá permitir o cadastro e a identificação dos equipamentos por meio de QR Code.

Ao consultar um equipamento, o usuário deverá visualizar as seguintes informações:


- Nome do equipamento;

- Número de patrimônio;

- Localização atual;
  
- Responsável atual;
  
- Situação do equipamento;
  
- Histórico de movimentações.

O sistema também deverá permitir registrar empréstimos, devoluções, transferências de localização e envio de equipamentos para manutenção. Com base nesse cenário, apresente:

1. O objetivo do sistema;

2. Os principais atores envolvidos;

3. Os requisitos funcionais numerados;
  
4. Os requisitos não funcionais numerados;

5. Os principais casos de uso.

Organize a resposta utilizando títulos e listas. Não adicione funcionalidades que não estejam relacionadas ao cenário apresentado.

---

# Resposta:

1. Objetivo do sistema

O sistema tem como objetivo facilitar o controle e o rastreamento dos equipamentos pertencentes à instituição de ensino, permitindo identificar sua localização, situação, responsável e histórico de movimentações.

---

2. Atores envolvidos:

Administrador: responsável pelo gerenciamento geral do sistema e dos equipamentos.

Servidor responsável pelo patrimônio: realiza cadastros e acompanha as movimentações.

Usuário autorizado: realiza consultas e pode registrar empréstimos e devoluções, dependendo de sua permissão.

---

3. Requisitos funcionais

RF01. O sistema deve permitir cadastrar equipamentos.

RF02. O sistema deve armazenar informações como nome, número de patrimônio, localização, responsável e situação.

RF03. O sistema deve gerar ou associar um QR Code a cada equipamento.

RF04. O sistema deve permitir consultar as informações de um equipamento por meio da leitura do QR Code.

RF05. O sistema deve permitir registrar empréstimos.

RF06. O sistema deve permitir registrar devoluções.

RF07. O sistema deve permitir alterar a localização de um equipamento.

RF08. O sistema deve permitir registrar o responsável atual pelo equipamento.

RF09. O sistema deve permitir registrar equipamentos enviados para manutenção.

RF10. O sistema deve manter o histórico das movimentações realizadas.

RF11. O sistema deve permitir pesquisar equipamentos.

---

4. Requisitos não funcionais

RNF01. O sistema deve possuir controle de acesso por autenticação.

RNF02. A interface deve ser simples e de fácil utilização.

RNF03. As informações armazenadas devem possuir proteção contra acessos não autorizados.

RNF04. O sistema deve apresentar as informações dos equipamentos de forma rápida.

RNF05. O sistema deve manter o histórico de movimentações sem permitir alterações indevidas.

---

5. Principais casos de uso

Cadastrar equipamento;

Consultar equipamento;

Ler QR Code;

Registrar empréstimo;

Registrar devolução;

Alterar localização;

Registrar manutenção;

Consultar histórico de movimentações.
