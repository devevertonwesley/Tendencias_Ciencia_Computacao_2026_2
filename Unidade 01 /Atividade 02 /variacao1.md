# Variação 1 — Mudança de Persona

# Técnica utilizada

Nesta variação, foi utilizada a técnica de mudança de persona. Em vez de solicitar que a IA atuasse
apenas como analista de sistemas, foi definido um papel mais específico.

---

# Prompt

Atue como um engenheiro de software especializado no desenvolvimento de sistemas para instituições de ensino.

Uma instituição de ensino precisa desenvolver um Sistema de Rastreamento de Equipamentos para controlar computadores, notebooks, projetores, tablets e equipamentos de laboratório.

O sistema deve permitir identificar a localização dos equipamentos, registrar empréstimos e devoluções, identificar o responsável pelo equipamento e consultar o histórico de movimentações.

Identifique os principais requisitos funcionais e não funcionais.

Além disso, indique quais funcionalidades devem ser priorizadas na primeira versão do sistema.

Organize a resposta em uma tabela.

---

# Resposta: 

| Categoria               | Descrição                              |
| ----------------------- | -------------------------------------- |
| Requisito Funcional     | Cadastrar equipamentos                 |
| Requisito Funcional     | Registrar localização dos equipamentos |
| Requisito Funcional     | Registrar responsáveis                 |
| Requisito Funcional     | Registrar empréstimos                  |
| Requisito Funcional     | Registrar devoluções                   |
| Requisito Funcional     | Consultar histórico de movimentações   |
| Requisito Não Funcional | Possuir autenticação de usuários       |
| Requisito Não Funcional | Possuir interface simples              |
| Requisito Não Funcional | Garantir segurança dos dados           |
| Requisito Não Funcional | Apresentar bom desempenho              |

---

# Funcionalidades prioritárias

Para a primeira versão do sistema, devem ser priorizadas:

- Cadastro de equipamentos;

- Consulta dos equipamentos;

- Registro de localização;

- Registro de empréstimos e devoluções;

- Identificação do responsável;

- Consulta do histórico.

---

# Análise da variação

A mudança de persona tornou a resposta mais voltada para o desenvolvimento prático do sistema. A solicitação de funcionalidades prioritárias também ajudou a identificar quais recursos poderiam fazer parte da primeira versão.

Entretanto, a resposta ainda apresentou requisitos relativamente genéricos e não detalhou como seria realizada a identificação dos equipamentos.
